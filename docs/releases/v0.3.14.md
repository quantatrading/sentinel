# Sentinel 0.3.14

Approve your security baseline through Telegram without opening an SSH session:

1. Send `/baseline review` and inspect the inventory; use additional review pages
   as needed. Approval accepts the whole inventory, including other pages.
2. If the setup is expected, send the exact `/baseline approve DIGEST` command
   supplied by the bot, in the same chat and from the same authorised user within
   five minutes.
3. Send `/baseline` to confirm the saved reference.

Changed, unavailable or stale inventory is rejected. The reference and approving
actor are saved before acknowledgement, persist across restarts and are audited.
File observations can be up to 60 seconds old; approval uses the sampled inventory.
All authorised Telegram users may replace this reference. The collector remains
read-only and receives no commands or credentials. No host configuration is altered.
Local-root approval remains supported; see the README for precedence rules.

## Upgrade on Ubuntu

Download the archive and checksum from this release into the same directory:

```bash
sha256sum --check --strict sentinel-0.3.14.tar.gz.sha256
tar -xzf sentinel-0.3.14.tar.gz
cd sentinel-0.3.14
sudo ./install.sh
```

The installer preserves configuration, credentials and state and restarts Sentinel
only. Check `/selftest` after upgrading. Do not uninstall first. Keep a protected
backup of configuration and state; downgrades are not guaranteed compatible.

Tests cover approval persistence and drift, review binding and expiry, stale or
changed observations, pagination, local-baseline precedence and failed saves.
The existing Ubuntu deployment is owner-confirmed; this new Telegram interaction
still needs a live check after upgrade. No live server was changed during development.

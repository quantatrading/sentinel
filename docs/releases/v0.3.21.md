# Sentinel 0.3.21

Snap auto-approval now defaults to on. Upgrades preserve an explicit existing
setting, including `false`. Use Telegram to manage the setting without a restart.

- `/snapapproval` shows the current setting.
- `/snapapproval off` requires manual approval for newly verified Snap refreshes.
- `/snapapproval on` enables automatic approval for newly verified Snap refreshes.

Sentinel saves and audits changes from authorised Telegram users before replying.
The existing evidence checks and grouped acceptance notice still apply.

## Upgrade

Download the archive and checksum into the same directory on the Ubuntu host.

```bash
wget https://github.com/quantatrading/sentinel/releases/download/v0.3.21/sentinel-0.3.21.tar.gz
wget https://github.com/quantatrading/sentinel/releases/download/v0.3.21/sentinel-0.3.21.tar.gz.sha256
sha256sum --check --strict sentinel-0.3.21.tar.gz.sha256
tar -xzf sentinel-0.3.21.tar.gz
cd sentinel-0.3.21
sudo ./install.sh
```

The installer preserves existing configuration, state, and credentials, and
restarts Sentinel. Use `/snapapproval` to check the effective setting.

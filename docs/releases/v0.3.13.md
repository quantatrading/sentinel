# Sentinel 0.3.13

First packaged public release of the Ubuntu 24.04 Gunbot watchdog.

- Telegram status, security, network and health reports.
- Sampled process, DNS, SSH, listener and security-baseline observations.
- Management-IP rules, maintenance windows and bounded WHOIS enrichment.
- Root collector separated from unprivileged Telegram handling.
- Installer, uninstaller and complete configuration/operations documentation.

The project owner has tested Sentinel on Ubuntu and confirmed it working.
Release automation runs unit tests, validates configuration and shell syntax,
then verifies both the archive checksum and every packaged file. It does not
run the privileged disposable-VM test or send live Telegram messages.

## Download and install

Download `sentinel-0.3.13.tar.gz` and `sentinel-0.3.13.tar.gz.sha256` from this
release into the same directory. On Ubuntu:

```bash
sha256sum --check --strict sentinel-0.3.13.tar.gz.sha256
tar -xzf sentinel-0.3.13.tar.gz
cd sentinel-0.3.13
sha256sum --check --strict SHA256SUMS
sudo ./install.sh
```

Review the README before installation. Ubuntu 24.04, running systemd, an active
systemd-resolved and a dedicated Telegram bot are required. No Python packages
need installing. Existing installations are upgraded by running the installer
without arguments; configuration and state are preserved.

Checksums detect corruption, not publisher authenticity. Obtain files from the
trusted repository release. Monitoring limits and Telegram/WHOIS data flows are
explained in README.md and SECURITY.md. No open-source license has been selected.

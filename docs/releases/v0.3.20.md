# Sentinel 0.3.20

Sentinel verifies Snap auto-refresh mount-link changes using local snapd history.
When the completed mount and removal tasks match the exact revisions and both
symlink fingerprints match the expected targets, Telegram shows one alert with
the evidence and one approval reference for both links.

Automatic approval is off by default. To opt in, set
`"auto_approve_snap_refresh": true` in the Sentinel JSON configuration and
restart the service using the [configuration guide](https://github.com/quantatrading/sentinel/blob/v0.3.20/docs/configuration.md#snap-auto-refresh-changes).
Sentinel queues a Telegram notice confirming acceptance before it saves the
baseline update. If it cannot queue the notice, the pair stays available for
manual review. Unmatched changes and unrelated drift follow the usual review flow.

## Upgrade

Download the archive and checksum into the same directory on the Ubuntu host.

```bash
sha256sum --check --strict sentinel-0.3.20.tar.gz.sha256
tar -xzf sentinel-0.3.20.tar.gz
cd sentinel-0.3.20
sudo ./install.sh
```

The installer preserves existing configuration, state, and credentials, and
restarts Sentinel. Send `/selftest` to check Telegram delivery after upgrading.

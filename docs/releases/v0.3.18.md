# Sentinel 0.3.18

Change the required Gunbot instance count through Telegram and simplify health alert headings.

- `/instances` shows the required count. `/instances 2` sets it to 2.
- Counts must be whole numbers from 1 to 256. Existing Telegram authorization applies; changes are audited and saved before confirmation, then used on the next monitoring check without a restart.
- Health alerts show one `HEALTH OBSERVATION` heading instead of separate `OBSERVATION` and `HEALTH` headings.

## Upgrade

Download the archive and checksum into the same directory:

```bash
sha256sum --check --strict sentinel-0.3.18.tar.gz.sha256
tar -xzf sentinel-0.3.18.tar.gz
cd sentinel-0.3.18
sudo ./install.sh
```

Only Sentinel restarts; existing configuration, state and credentials are preserved.
Send `/selftest` and `/instances` after upgrading. To change the required count,
send `/instances 2` (replace 2 with your required count), then check `/status`.
